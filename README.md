Quantum Gauntlet is 3D isometric local multiplayer arena brawler. It supports up to four players playing in Free For All or teams.

# Getting Started
1. Install Unity 2021.3.45
2. Export to desired runtime
3. Run appropriate executable in QUANTUMGAUNTLET directory.
4. Play!

Quantum Gauntlet is 3D isometric local multiplayer arena brawler. It supports up to four players playing in Free For All or teams.


![image](https://github.com/user-attachments/assets/dc7da094-8a14-4391-be6d-1fa5b10c9cdb)



# Gameplay
Features a dynamic combat system with mana resources, combos, and power-ups. Contains a custom physics engine for juggling your opponents through the air. Models, animations, textures, shaders, sfx & music - all done from scratch! Supports gamepad and keyboard with an in-game tutorial to go over the basic controls.

# Getting Started
1. Install Unity 2021.3.45
2. Export to desired runtime
3. Run appropriate executable in QUANTUMGAUNTLET directory.
4. Play!
